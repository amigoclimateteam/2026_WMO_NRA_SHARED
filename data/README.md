# Output Data

This directory is used to store all intermediate and final outputs generated by the project workflows.

Users do not need to manually create the internal folder structure. When the corresponding notebooks are executed, the required subdirectories will be automatically created if they do not already exist.

## Generated Structure

During processing, the notebooks will generate a set of subfolders used to organize the outputs required by the methodology.

The most important directories are:

```text
output/
├── atlas_data/
├── figures/
└── ...
```

## atlas_data

The `atlas_data` directory contains the final processed datasets produced by the workflow.

In particular, this folder stores the final **NetCDF** files that are subsequently used for atlas generation, map production, and downstream analyses.

## figures

The `figures` directory contains all graphical outputs generated during processing, including:

* Atlas maps
* Diagnostic plots
* Validation figures
* Intermediate visualizations

These outputs are automatically produced by the notebooks and saved in the appropriate subdirectories.

## Notes

The folder structure is managed automatically by the processing workflows. Users only need to execute the notebooks and ensure that all required input datasets are available in the expected locations.

Any missing output directory will be created automatically during execution.
